How the line is made

Each unit is one hand-written SVG at 320 by 400, in four colours: cream body, an amber or cyan signal, and the void as the outline between every part. No raster, no image generation, no external reference — the files are in assets/series/, each carrying its own title and role, and each under four kilobytes.

The palette is the site's own. --amber, --cyan, --cream and --alert were added to assets/tokens.css with their measured contrast, so a unit never carries a colour the design system has not accounted for: amber and cyan clear 10.6:1 and cream 12.7:1 on the raised surface, and --alert is marks and edges only.

The pairing is a joke told with a straight face. Vellum files everything, so it fronts Qualia and its crash-safe evidence logs. Gauge reads heat before it reads words, so it fronts Mage. Dray runs manifests, so it fronts Reeldeal. Sextant holds every course at once, so it fronts Quantum Superposition.

The names are ours, the register is a broadcast ident, and nothing here is licensed from anything: no characters, no logos, no stills. Every face on this page was drawn in a text editor.
