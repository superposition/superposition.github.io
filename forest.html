The forest

A bear of three hundred triangles walks a low-poly forest and says what each repository is: twenty sentences, a new gesture at every stop. Every triangle is arithmetic in six files of JavaScript — no model file, no image, no library but the renderer.

Repository

{%- comment -%} One
  • per repository page, in the collection's own order, so the twenty sentences exist in the HTML, with their links, before any script runs. The sentence is the page's tagline — the one line the repository's own page already leads with — and falls back to the GitHub description in _data/repos.yml only if a page has no tagline, so nothing here is typed by hand and nothing can drift from the pages it describes. {%- endcomment -%} {%- assign catalogue = site.data.repos.repos -%} {%- assign repositories = site.repos | sort: "order" -%}

    The twenty sentences

    The same sentences the bear says, in order, with the link to each repository. This is what the page is without JavaScript, and what a screen reader reads.

      {%- for item in repositories -%} {%- assign handle = item.repo | split: "/" | last -%} {%- assign name = item.title | default: item.slug -%} {%- assign sentence = item.tagline | strip -%} {%- if sentence == "" -%} {%- assign entry = catalogue | where: "name", handle | first -%} {%- assign sentence = entry.description | strip -%} {%- endif -%}
    1. {{ name }}{{ sentence }}
      2. {%- endfor -%}

    The bear is made in code: a body, a head of eighty faces, two ears, a muzzle, a nose, four limbs and a tail, each one a primitive pushed through assets/forest/mesh.js. The gestures are one array of keyframes in assets/forest/bear.js; the forest is seeded, so it is the same forest on every load. Under prefers-reduced-motion: reduce he stands still, holds a pose, and the sentences arrive at once.
