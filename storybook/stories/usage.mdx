# When to use what

The workbench imports `assets/tokens.css` and `assets/notebook.css` directly. There is no Storybook-only stylesheet, so a story and the page it came from cannot disagree: if a component needs a new rule, the rule goes into the site's stylesheet and both places get it.

Three checks run in CI and fail the build, so this page is a description of the gate rather than advice:

| Check | Command | What fails the build |
| --- | --- | --- |
| Tokens | `npm run slop` | A colour, length, gradient, shadow, radius or font size written in `notebook.css` instead of named in `tokens.css`; a `var()` nothing declares; a token nothing reads; a component class no page renders; a story that does not name the page that adopts it |
| States and targets | `npm run a11y` | An interactive component with no hover, focus-visible or active state (or disabled, where it can be unavailable); a control under 24 × 24px at 1440 or at 360; an image with no alt or no width and height; a `<button>` with no type; an unlabelled input; an animation with no reduced-motion answer; `outline: none` |
| Contrast | `npm run contrast` | Any of the 71 colour pairs under 4.5:1 for text or 3:1 for a control edge, in any of the three identities |

## Two densities, one scale

Every gap on the site is on an 8px rhythm with one documented half step: `--space-half` 4, `--space-1` 8, `--space-2` 12, `--space-3` 16, `--space-4` 24, `--space-5` 32, `--space-6` 48–80, plus `--flow` (24, the paragraph break), `--space-section` (40–72) and `--space-open` (56–112).

A table or a repository index reads at `--density-row` (12) and `--density-cell` (16). `.table--compact` sets those two one step down (8 and 12) and nothing else changes, so the comfortable density and the compact density cannot drift apart.

## Button

**Use it** for an action — one per page. `/404.html` carries the only one on the site. **Do not use it** for navigation between pages, which is a link, or for more than one action on a view.

- `btn-primary` — amber fill carrying void type at 13.07:1, with the soft bloom; hover lifts to `--accent-peak` (15.37:1) and puts a `--star` edge on it, active presses one hairline down.
- States: hover, focus-visible (2px `--state` ring at 12.93:1, 4px offset), active, disabled. Disabled is `--dust` type (7.51:1) inside a dashed `--dust` edge, so an unavailable action is still readable and no fill is left to mistake for an available one.
- The box is 39.6px tall: `--space-2` by `--space-4` padding around 13px type.

## Link

Three kinds and no more. The bare link carries body copy (`--accent-text`, 13.07:1). `.text-link` is the chrome command — an underline drawn as a border, so it thickens on hover without reflowing the line, 30.1px tall. A prose link is `--nebula-text` (6.69:1) and only ever inside `.prose`: a citation reads differently from chrome.

## Card

One card, two jobs: a repository on `/projects/` and, where a journal entry is carded, the entry itself. Photograph, name, tagline, meta. The frame is the HUD box — one hairline and two amber corner ticks — and hover changes the title and the hairline only. No shadow and no lift: a shadow on a card is decoration standing in for hierarchy.

## Entry list

A journal row: ISO stamp in mono with tabular figures, a 6px `--state` mark drawn with a background so no reader hears it, then the title and the dek in the text face. `/journal/` groups the rows by topic; the home page shows the ten newest.

## Table

The data density. `/projects/` lists 33 public repositories in one compact table: name and description, language, stars, last push. Stars are right-aligned with tabular figures. The link is the whole cell, so a phone target is the column rather than the words in it. A prose table in an entry uses the same rules without the class, so a markdown table and a data table cannot look like two systems.

## Definition row

A label and its value for the facts a repository page opens with: language, stars, last push. Label at `--step-1` mono in `--dust`, value at `--step-2` mono 500 in `--star`, one hairline per fact. It replaced a line of plain meta text that gave the three facts the same weight as the tagline above them.

## Range control

A row of ranges over one long list with a count each — pagination without a second page. `/journal/` uses it for its topics: the site is static, so the whole journal is one document and a range is an anchor into it. An anchor has no disabled state; a range with no entries is not rendered.

## Notice

One inline notice: something true the reader needs before the prose, that is not the argument. A 2px `--state` edge on the raised ground. Three repository pages carry one, each summarising the caveat its page ends with. Red is not available here — red is the 404 and a photograph that failed, and a caveat is neither.

## Skeleton

What a page shows where a photograph has not arrived: a frame, the raised panel, and a label naming the file. It sits behind the hero image (z-index −4 against the image's −3), so it is visible while the file is in flight and covered the moment it paints; if the file fails, the label says so and the box does not collapse. No shimmer — the site does not animate to fill time.

## Empty state

What a page says when there is nothing to show: a title naming the absence, a line on what happens next, one way out. `/journal/` ships this state today, because the site publishes no entries.

## Poster and campaign block

A library advertised as a film. 2:3, key art at the top, type below on the void ground so every word sits on a measured background. A container query drops the logline at 260px and the credits at 340px rather than setting type below the scale's floor. The campaign block puts one poster beside the billing on a repository page; the strip runs the programme on the home page.

## Identities

Three identities are one attribute on `<html>`: `c` shipped, `a` instrument, `b` poster. No page sets it, so the workbench toolbar is the only place they are compared — `/style/` documents them. Every component reads semantic tokens, so an identity is `tokens.css` plus one scoped block.
