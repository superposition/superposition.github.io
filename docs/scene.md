# The scene

One drawing, three layers and an action, composed into one document and shown at
`/station/`. Everything here is vector, generated by a script, deterministic: the
same seed and the same bytes in, the same bytes out.

## The canvas

`viewBox="0 0 2400 1500"`. A layer's root carries no `width` or `height`, no
background and no filters; it has its own `<title>` and `role="img"`, so it stands
alone in a browser.

| Zone | Extent | Who draws it |
| --- | --- | --- |
| Station | x 560–1840, y 60–900 | `assets/scene/station.svg` |
| Traffic | x 0–2400, y 120–1240, behind and in front of the station | `assets/scene/traffic.svg` |
| City | x 0–2400, ground plane y 860–1500 | `assets/scene/city.svg` |

The palette is the site's, by name and by hex, because an SVG that stands alone
cannot read a stylesheet:

| Token | Hex | Use |
| --- | --- | --- |
| `--amber` | `#ffc24a` | the signal: carrier lines, lamps, the pulse |
| `--state` | `#8fd3ff` | state: docking geometry, alignment beam, live fittings |
| `--cream` | `#efe6d3` | structure |
| `--dust` | `#a79085` | secondary structure, haze, tracks |
| `--alert` | `#e2402f` | alert, sparingly — 9 marks in the whole composition |
| `--void` | `#000000` | the ground |

Line weights are 1, 2 and 4 only. Depth comes from value and weight, not hue.

## The composition

`scripts/scene/compose.py` reads the three layers, keeps their z-order and writes
`assets/art/station.svg` plus the same bytes at `_includes/scene/station.svg`,
which `station.html` includes inline so the groups are in the page's DOM for CSS
and for a script. The page cannot read the file any other way without a plugin,
and the two paths are written in one invocation, so they cannot drift:

```
python scripts/scene/compose.py              # both files, seed 20261127
python scripts/scene/compose.py --check      # exit 1 if either is stale
python scripts/scene/compose.py --layers DIR # compose from a directory of layers
python scripts/scene/compose.py --out FILE   # one path, for a quick look
```

The include is the whole swap: `{% include scene/station.svg %}` is one line,
the file is a complete SVG with its own title and no wrapper markup, so a page
that has a WebGL version of the scene can replace that one line with it as the
static answer. Its accessible-name ids are `station-scene-title` and
`station-scene-desc` rather than `scene-title` / `scene-desc`, because the map's
own still (`_includes/scene/map.svg`) already owns those in this repository and
two documents can end up on one page.

Bands, in document order. Every one of them is present in every build, including
the ones whose layer has not landed, so a script can address them unconditionally:

| Group | Contents |
| --- | --- |
| `#scene-ground` | the void rectangle the whole canvas sits on |
| `#scene-city` | the city layer |
| `#scene-traffic-back` | the traffic layer's far band (`#traffic-back`) |
| `#scene-haze` | the dust pass — generated here, 1px, behind the station |
| `#scene-station` | the station layer |
| `#scene-traffic-front` | the traffic layer's near band (`#traffic-front`) |
| `#scene-action` | the action — generated here |

The compositor is also where a layer's ids are made safe: each is prefixed with
the layer's name (`city-ground`, `station-collar`), and every `url(#…)` and
`href="#…"` that pointed at one is rewritten with it. The ids above, and the
action's own (`#docking-shuttle`, `#alignment-beam`, `#alignment-line`,
`#dock-arm`, `#dock-mark`, `#signal-carrier`, `#signal-pulse`, `#drone-a`,
`#drone-b`), are reserved and never prefixed.

A layer that is missing is drawn as a placeholder frame with its own name in it,
and the header comment of the composed file says so. The scene is still a valid
document, and a re-run once the layer lands replaces the frame.

## The action

The action is placed from the station *zone* in the contract, not from a
measurement of the station drawing: the drawing is fitted into the zone, so the
truss, the hoop and the approach line land in the same place whatever seed drew
the station. The fractions are module constants in `compose.py`:

| Primitive | Parameter | Value |
| --- | --- | --- |
| Truss line | y, x range, as fractions of the zone | 0.58 of the height → y 547.2; 0.05–0.88 of the width → x 624–1686 |
| Docking hoop | centre, as fractions of the zone | (0.95, 0.74) → (1776, 681.6) |
| Boom | hull anchor → hoop | (0.84, 0.70) → (1635.2, 648) to the hoop |
| Shuttle | centre, as fractions of the zone | (0.40, 0.86) → (1072, 782.4), clamped above y 836 |
| Alignment beam | cone, gates, centreline | edges ±24 at the hoop; gates at 0.34, 0.55, 0.74 of the beam with half-lengths 27, 20, 14; a 2px centreline dashed `12 8` |
| Drones | two cubic arcs, phase, size | `M-90 690 C760 556 1560 512 2490 640` at 0.34, 13 units; `M2490 300 C1720 236 880 372 -90 306` at 0.62, 10 units |
| Pulse | carrier, dot, tails | 1px amber carrier on a 96-unit tick pitch; a 4px amber dot, a 2px tail of 38 units and a 1px tail of 66 |
| Haze | count, length, opacity, dash | 34 runs of 120–760 units at 0.07–0.17, 42% of them dashed `2 7`; 5 curves at 0.12 |

The haze, the ticks and the pulse's starting point are the only seeded parts of
the action; everything else is a fraction of the zone, so a new seed moves the
atmosphere and leaves the staging alone.

## Motion

`assets/art/station.svg` is a still. `station.html` moves it in CSS, with no
script, by naming the composed document's groups. Each handle is a bare group —
the transform that places the thing sits on a child — so the handle's own
transform belongs to the animation, and to the next thing that drives it.

| Handle | Property | Duration, curve |
| --- | --- | --- |
| `#scene-city`, `#scene-traffic-back` | `transform` — 9 units | 120s, ease-in-out, alternate |
| `#scene-station` | `transform` — 15 units and a 6-unit lift | 96s, ditto |
| `#scene-traffic-front` | `transform` — 30 units and a 6-unit lift | 72s, ditto |
| `#signal-pulse` | `transform`, `opacity` — 1062 units, the truss | 16s, linear |
| `#alignment-line` | `stroke-dashoffset` — 20 units | 6s, linear |
| `#docking-shuttle` | `transform` — 26 units along the approach | 20s, ease-in-out, alternate |
| `#drone-a`, `#drone-b` | `transform` — 26 and 22 units | 44s, ease-in-out, alternate |

Seven animated properties in five keyframe sets, on eleven elements. The frame
clips, so the drift can never show an edge. `prefers-reduced-motion: reduce`
stops all of it and hides the pause switch; the *Hold the scene* switch pauses it
without leaving the page, which is the WCAG 2.2.2 answer for motion that runs for
minutes. Nothing on the page depends on the animation to be visible or readable:
stopped, the drawing is exactly where the file put it.
