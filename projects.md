## Mage — understanding GPU kernels

The first investigation follows linear algebra into the machine. It asks how repeated structure creates opportunities for reuse, where parallel work must come together, and how local interactions become a larger computation.

Small GPU experiments make these questions concrete. The public field notes develop the ideas; the code and evidence stay available in GitHub.
