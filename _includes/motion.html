{%- comment -%} The motion layer's way onto a page (GALA-87). A page asks for motion with `motion:` in its front matter; _config.yml sets one for every entry and every repository page, and the home page sets its own. This include is everything that buys: the boot snippet, the vendored GSAP build, and the one runtime. The snippet's only job is to mark the first frame, so a scrubbed opening does not flash its finished state before the runtime builds it. It refuses to mark anything for a reader who asked for reduced motion, and it takes the mark off again a second and a half later if the runtime never arrives — so a script that fails to load ends as the static page instead of as a blank hero. Nothing else on the site is ever hidden for the runtime's benefit. SplitText is only loaded for the opening, which is the only scene that splits type. Every other page pays for GSAP and ScrollTrigger and nothing more. {%- endcomment -%} {%- if page.motion == 'opening' %} {%- endif %}
